
# Bootstrap Lab 07

## Web Engineering

### Objective
To practice Bootstrap 5 components and create responsive web layouts.

## Tasks Completed

1. Containers, Grid Rows and Columns
2. Responsive Grid Layout using Container Fluid
3. Nested Grid Layout
4. Form Layout using Bootstrap Grid
5. Bootstrap Success Alert
6. Bootstrap Card Component
7. Product Grid using Cards
8. Bootstrap Button Group

## Technologies Used
- HTML5
- Bootstrap 5
- CSS

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
